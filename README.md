# Dépenses Dauphine — V2.1

Version PWA mobile de suivi des dépenses étudiantes.

## Nouveauté V2.1
- Icône d'application Dauphine sur iPhone/iPad
- Icônes PWA 180, 192 et 512 px
- Apple Touch Icon configurée
- Cache service worker mis à jour

Après déploiement, supprimer l'ancienne icône de l'écran d'accueil puis ajouter de nouveau le site à l'écran d'accueil pour que l'icône Dauphine apparaisse.
